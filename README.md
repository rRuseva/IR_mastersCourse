## 🔎 Information Retrieval — PubMed Search Project

A **Python Information Retrieval system** for collecting, indexing, and searching biomedical publications from PubMed.

The project was developed as part of my **Information Retrieval course** and implements the main stages of a traditional search engine pipeline — from collecting and preprocessing textual data to building an inverted index and calculating document-term weights for information retrieval.

The repository also contains exercises completed throughout the Information Retrieval course.

### Technologies

**Python · Scrapy · TF-IDF · Inverted Indexing · Text Processing · Web Scraping**

- Text preprocessing
- Web scraping and data extraction
- Inverted indexes

- Document indexing
- Query processing
- Search and document retrieval

## 🧬 PubMed Course Project

The main project implements an **Information Retrieval pipeline for biomedical publications from PubMed**.

The system consists of two main parts:
1. **Data collection** — a Scrapy-based crawler extracts publication data from PubMed.
2. **Information retrieval** — the collected documents are preprocessed, indexed, weighted, and searched using classical Information Retrieval techniques.
